A static, offline dashboard that ranks pre-token DeFi protocols by implied value, with a farm plan for each. The value model calibrates each category against its traded peers, using DefiLlama's sealed 2026-11-14 snapshot of 758 protocols.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
